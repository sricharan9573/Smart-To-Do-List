# Mega Prompt: Smart To-Do List Web Application with Supabase Backend

Build a complete, modern, responsive **Smart To-Do List Web Application** with a professional user interface and a fully functional backend connected to **Supabase**.

The application should be beginner-friendly to develop and maintain, but the final output should look like a polished, production-style productivity application.

## 1. Technology Stack

**Frontend:**
- React.js with Vite.
- HTML5, CSS3, and JavaScript.
- Tailwind CSS for styling.
- Lucide React for icons.

**Backend and Database:**
- Supabase for the backend.
- Supabase PostgreSQL database for storing tasks and user profiles.
- Supabase Authentication for user registration and login.
- Supabase Row Level Security (RLS) to protect user data.
- Supabase JavaScript client for frontend-to-backend communication.

**Development environment:**
- Replit for writing, running, and previewing the application.
- Use environment variables to store Supabase credentials securely.

## 9. Supabase Database Structure

Create the following database tables.

### Table 1: profiles

| Column | Type | Description |
|---|---|---|
| id | UUID | Primary key, references auth.users |
| full_name | TEXT | User's full name |
| created_at | TIMESTAMPTZ | Account creation time |

### Table 2: tasks

| Column | Type | Description |
|---|---|---|
| id | UUID | Primary key, generated automatically |
| user_id | UUID | References auth.users |
| title | TEXT | Task title |
| description | TEXT | Task description |
| due_date | DATE | Task due date |
| due_time | TIME | Optional due time |
| priority | TEXT | Low, Medium, High |
| category | TEXT | Task category |
| status | TEXT | Pending or Completed |
| reminder_enabled | BOOLEAN | Whether a reminder is enabled |
| created_at | TIMESTAMPTZ | Creation timestamp |
| updated_at | TIMESTAMPTZ | Last update timestamp |

Add suitable constraints, indexes, default values, and foreign keys.

## 10. Supabase Security

Configure Row Level Security for all user-specific data.

**Security requirements:**
- Enable RLS on the profiles and tasks tables.
- Users can read only their own profiles and tasks.
- Users can insert tasks only with their own user ID.
- Users can update and delete only their own tasks.
- Users cannot modify another user's records.
- Use secure database policies based on `auth.uid()`.
- Never expose the Supabase service role key in frontend code.
- Store the Supabase project URL and anonymous/publishable key in Replit Secrets or environment variables.
- Validate user input before sending it to the database.

Provide the complete SQL script for creating the tables, indexes, triggers, and RLS policies.

## 14. Replit Setup and Supabase Connection

1. Create a new React + Vite project in Replit.

3. Create a new Supabase project.
4. Open the Supabase SQL Editor.
5. Execute the SQL script to create the database tables and RLS policies.

7. Add the following secrets to Replit:

```env

VITE_SUPABASE_ANON_KEY=your_supabase_publishable_or_anon_key
```

8. Initialize the Supabase client using these environment variables.
9. Implement registration and login.
10. Connect task creation, retrieval, editing, and deletion to Supabase.
